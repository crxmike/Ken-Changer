Introduction

Kenwood Corporation in now producing a 200 disc CD changer and 400+3 DVD changer that has the capability of communicating with a computer for the control of changer functions and the specification of disc title and track information. This capability (coined PC-Link by Kenwood) allows a much simpler way to have an extensive collection of discs accurately cataloged within the player.

The PC-Link functionality is available in their model CD-4700M, CD-4260M, and CD-425M cd changers as well as the DV-5050M and DV-5900M dvd changers. The changer is attached to a computer using a null-modem serial cable, and using the NetNamer program available from Kenwood, player function and disc information can be controlled from the computer. Unfortunately the NetNamer program is a VisualBasic application and will therefore only run on the Windows platform.

The goal of this document is to sufficiently describe the underlying serial protocol used to communicate with the changers so that users of other computer platforms can also access the PC-Link functionality of their Kenwood Mega-Changer.
