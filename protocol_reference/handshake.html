Handshake

Initiate a session. Computer sends a identifier of "I'm PC" and the player responds with a similar payload (see below for currently known contents).

Payload

Data Type Parameter Name
string identifier

Notes

The known values for identifier are listed below. If you have a changer where no identifier is listed please contact me.
