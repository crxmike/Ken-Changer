DiscTOC

Information about a discs TOC.

Payload

Data Type Parameter Name Description
short slot slot number
byte page_num data page (47? TOC values per page)
byte format format of disc
byte first_track number of first track
byte last_track number of last track
repeated (last_track-first_track+2) times
toc_time time start time of track n

Notes

A maximum of 99 tracks are listed.
