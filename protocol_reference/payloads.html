Protocol Payloads

The table provides links to descriptions of the various data frames sent as part of an event/request/reply payload. Each protocol frame description will consist of a description of the particular event/request/reply, and the payload that acompanies it. The payload is listed with one parameter per line with the data type first, followed by the parameter name, followed by an optional description of the possible values. All values that occupy more than one byte are encoded using LSB byte order. Where unknown values exist, the identifier will be named unknown. In some cases the values of a parameter are not currently known and are usually preceeded by a '?'
