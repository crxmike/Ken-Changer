InfoEvent

Current changer info.

Payload

Data Type Parameter Name Description
short slot slot number
byte track track number
byte program program number
byte num_tracks track count
byte userfiles bit or'd combination of userfiles
byte param userfile or genre
byte mode mode
bool repeat repeat on

Notes

param is a userfile when mode = 0x07, 0x08, or 0x09

param is a genre when mode = 0x05, or 0x06

program is only set in program mode
